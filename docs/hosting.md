# 主持指南

活動當天主持人要知道的事：開房、操作、出狀況怎麼救。規則本身見 [完整規則](rules.md)。

## 開房與大廳

主持人在首頁按「主持遊戲」，進到主持人頁（`/room/<代碼>/host`）。主持人頁最上方就是大螢幕網址，在電視或投影機開（`/room/<代碼>/screen`）。
每隊用手機輸入隊伍名稱和 4 碼房間代碼加入，或掃大廳的 QR。隊名不能和已經加入的隊伍相同，只差大小寫或全形半形也算同名。等待時，手機上看得到所有已加入的隊伍。主持人頁的大廳每隊有「改名」（規則和加入時一樣）和「移除」：被移除的手機會顯示「主持人把你們的隊伍移除了」，自己重連不會再加回去，要回首頁重新打開房間才能再加入。主持人按「開始遊戲」。

等人時大螢幕中間是營火，每隊加入時角色會跑進來圍著營火；房間代碼與加入 QR 也在這裡。

## 玩法說明

「開始遊戲」上方有「開始前播放玩法說明」，新房間預設勾選，按「回到大廳，再玩一場」後預設不勾。勾選時，大螢幕先播 4 頁說明（輪流上陣、用手機作答、答錯怎麼辦、怎麼贏），主持人頁有每頁的講稿提示，按「下一頁 ▶」（或鍵盤 → / Enter，← 回上一頁）翻頁，第 4 頁按「開始冒險 ▶」才開始擲先攻，擲完才出第一題、放開場音效和旁白。說明播放時手機顯示「看大螢幕 👀」和目前第幾頁；大螢幕的語音開著時會唸貓頭鷹那一句。見 [docs/designs/how-to-play.md](designs/how-to-play.md)。

**擲先攻**：說明結束後（沒勾說明就是按「開始遊戲」後），各隊用手機擲 d20 排出輪流順序，大螢幕排出每隊的骰子和倒數。主持人頁顯示已擲幾隊，「🎲 全部代擲」一次替還沒擲的隊伍擲完；15 秒後沒擲的隊伍由系統代擲。順序出來後大螢幕停約 4 秒，才出第一題。細節見[完整規則](rules.md#回合與題庫)。

擲先攻開始時，大螢幕先播約 2 秒的石門打開；第一次輪到首領房時，播約 2.5 秒的「首領出現！」警報橫幅（🎵 音樂開著時有警報聲）。底下的題目和旁白照常進行。電腦設定「減少動態效果」時，兩段都只停一格靜止畫面。中途才打開或重新連線的大螢幕不會補播。

## 大螢幕

**活地圖**：遊戲進行時，大螢幕上方是一條地城地圖（取代原本的隊伍卡）。每隊是一個標著隊名首字的小棋子，答對就走進下一間房；最前面那隊之後是迷霧，看不出還剩幾間。首領房一開始是關著的門，第一隊進去後門才打開，顯示首領和血條。輪到的隊伍棋子上方有 ▼，離線的隊伍顯示「zz」。地圖不顯示分數。設計見 [docs/designs/live-map.md](designs/live-map.md)。

**地城主（旁白）**：每次判分後，貓頭鷹魔法師會先說結果，再點名下一隊；隊伍進首領房時也會特別宣告。輪不到的隊伍在手機上看到輪到誰、面對哪隻怪物、自己的獎勵分和同一句旁白，還可以點 👏😱😂👎，讓表情在大螢幕背景飄過（見[完整規則](rules.md#觀眾反應)）。遊戲結束時旁白先念大成功王，再從第三名念到第一名，大螢幕一名一名亮出頒獎台，最後是一段後記（見[完整規則](rules.md#勝負與再玩一場)）。後記長到大螢幕一頁放不下時會分頁，主持人頁出現「◀ 上一頁」「下一頁 ▶」和「後記 1／2」，由主持人翻頁；大螢幕的語音開著時，每翻一頁念那一頁。打倒首領時，等尾刀的 4 顆骰子停完；首領有菜的話，大螢幕還會先在中央把首領下鍋、端出今晚的大菜，約 4.6 秒後才開始念名次。答對打倒有菜的怪物時，主持人頁先出「🍲 上菜」（鍵盤 `1`），按了大螢幕才煮這道菜，再按一次才進下一題（見[完整規則](rules.md#怪物變料理)）。旁白預設是腳本句，有 API 金鑰時可以改用 Claude 即時寫（見下面的 [AI 旁白](#ai-旁白)）。大螢幕右下角有一個語音開關（用瀏覽器內建的 Web Speech API 把旁白念出來），預設關閉，開關狀態記在該裝置上；沒有語音 API 的瀏覽器不會顯示這顆按鈕。旁邊還有「🎵 音樂」開關，打開後大螢幕會播程式合成的背景音樂，判分時也會有音效（旁白念出來時音樂會自動壓低）；同樣預設關閉、記在該裝置上。

**YouTube 題**：影片只在大螢幕播。主持人頁輪到隊伍的面板裡有 ▶ 播放、⏸ 暫停、⟲ 從頭三顆鍵，亮綠色的是你最後下的指令：▶ 或 ⏸（按 ⟲ 之後亮 ▶）；⟲ 一律從片段開頭重播。影片播放時背景音樂完全靜音，正在念的旁白也會停。聽歌題公布答案時，如果沒有圖片或影片詳解，大螢幕拿掉像素卡露出畫面，影片停在原位置，可以再按 ▶ 接著放。瀏覽器規定網頁被點過才能放有聲音的影片：大螢幕還沒被點過時，大廳頂端會提醒「點一下大螢幕」，開場前點一下就好。設計見 [docs/designs/youtube-questions.md](designs/youtube-questions.md)。

**螢幕不休眠**：主持人頁和大螢幕開著時會要求螢幕保持亮著（Screen Wake Lock），切走再回來會重新要求。瀏覽器不支援、低電量拒絕，或不是 HTTPS（例如區網試玩的 `http://` 網址）時，螢幕照舊會休眠。

## AI 旁白

預設是腳本旁白，不用金鑰、不花錢。主持人在大廳的「AI 旁白」區選一種：

- **不用 AI**：腳本旁白（預設）。
- **用我自己的 Anthropic API key**：貼上自己的 key，按「驗證並使用」。伺服器先打一次 Anthropic 確認 key 有效才啟用。勾「記住這台電腦」才會存在這台瀏覽器（localStorage），否則重新整理後要再貼一次。建議開一把專用的 key，並在 Anthropic Console 設花費上限。
- **站長金鑰**：輸入站長的 `OWNER_KEY`，改用伺服器自己的 `ANTHROPIC_API_KEY`。伺服器兩個都有設定才能用。

每個房間預設最多 300 句 AI 旁白（主持人可以改，上限 5000），用完會問主持人要不要提高上限，或改回腳本。

主持人的 key 只存在房間的記憶體裡，不會寫進快照、不會記錄、也不會傳回任何畫面，主持人頁只顯示最後 4 碼（見 [SECURITY.md](../SECURITY.md)）。伺服器重啟後要再貼一次。站長金鑰只在伺服器（Worker）讀取，不要加 `NEXT_PUBLIC_` 前綴，否則會進到瀏覽器。旁白用 `claude-haiku-4-5`，遊戲結束的後記用 `claude-sonnet-5-5`。每句旁白最多等 3 秒（後記 15 秒），逾時、出錯或內容不合格就改用腳本句；連續失敗 3 次或金鑰被拒絕（401/403）就整個房間改用腳本。玩家輸入的隊伍名稱只會以資料的形式進提示詞，題目和答案完全不會進提示詞。提示詞會附上這個房間最近 8 句 AI 旁白，請模型換個說法、不要重複用詞；伺服器重啟或房間代碼交給下一位主持人後就清空。

> **費用**：AI 旁白要主持人自己的 key 或站長金鑰才會開，每個房間有句數上限；站長金鑰的花費上限見[部署指南](deployment.md#ai-旁白的金鑰)。

主持人頁「答對！」上方有「地城主旁白」面板，平常收成一行（例如「3 句・念到第 2 句」），點開會列出大螢幕這次要念的每一句。還沒念完的句子按「改」就能換掉（最多 50 字），大螢幕從改的那句接著念；已經念完的句子不能改。面板下方是「下一句這樣說」（排一句最多 40 字的話，下一次旁白的第二句會說出來，見 [docs/designs/host-next-line.md](designs/host-next-line.md)）。設計見 [docs/designs/host-narration-edit.md](designs/host-narration-edit.md)。`⚙ 更多` 裡有旁白紀錄下載（每句的事件、當時分數、來源、延遲和備援原因；伺服器重啟後會消失）。

站長金鑰和伺服器端的設定見 [部署指南](deployment.md#ai-旁白的金鑰)。

## 出狀況時

**斷線提示**：手機或大螢幕斷線時會顯示「連線中斷，重新連線中…」；手機重新連上後，會告訴這隊離線期間是否被跳過、或期間判了幾題。

**連不上與被拒絕加入**：手機、大螢幕或主持人頁第一次連線 10 秒還沒連上，會顯示「連不上伺服器：請檢查網路，或稍後再試。」和「重試」按鈕。手機被房間拒絕加入時，會用一句話說明原因（遊戲已經開始、隊伍名稱不能用、隊名已經有人用了、房間已滿、瀏覽器存的隊伍資料對不上、密碼不對或需要密碼、隊伍被主持人移除），並附連結：密碼問題回到輸入密碼，其餘回首頁。

**換手機接手隊伍**：遊戲開始後，手機沒電、換了瀏覽器或用無痕分頁時，主持人頁每隊都有「交給新手機」，按下去會顯示一組 4 碼配對碼（這隊還在線上時會先確認）。新手機打開房間網址，在被拒絕的畫面「換了手機？輸入主持人給的配對碼：」輸入配對碼，按「接手隊伍」，就接回這隊，分數和輪次都在。配對碼只能用一次，5 分鐘內有效，再按一次會換成新碼；房間裡輸錯 5 次，所有還有效的配對碼都作廢，主持人要再按一次。舊手機回來也還能幫這隊玩。設計見 [docs/designs/team-handoff.md](designs/team-handoff.md)。

**畫面出錯時**：頁面當掉時顯示「畫面出錯了」和「重新載入」按鈕，不會只剩一片白；重新載入就回到遊戲，分數和進度都還在。每次當掉會送一行回報給 Worker（`POST /api/client-error`），Worker log 裡是 `{"event":"client_error",…}` 的 JSON。

## 已知限制

- **沒人用的房間會休息、再被忘記**：房間 2 小時沒有任何會改變狀態的動作（加入、開始、判定、改旁白等；下載旁白紀錄和觀眾反應不算），就用關閉碼 4001 關掉所有連線，遊戲進度保留；三個畫面顯示「房間休息中」並**不再自動重連**，點「重新連線」就接回原局。這是為了避免電視忘了關、整晚被計費（Cloudflare 免費方案每天 13,000 GB-s，一個房間開滿 24 小時約用掉 83%）。連 24 小時都沒有動作，房間會被整個清除、代碼釋放，還連著的畫面會收到關閉碼 4002 並顯示「房間已過期」，重新連線會進到全新的空大廳。自動重連不算動作，所以電視沒關也不會讓房間永遠不休息。時間可用環境變數 `ROOM_IDLE_MS`、`ROOM_EXPIRE_MS`（毫秒）調整。首頁「主持遊戲」建立的房間若剛好撞到別人還在的代碼，主持人頁會自動換一組新代碼；直接打開既有房間的連結則永遠不會換。
- **主持人身分靠金鑰**：建立房間時瀏覽器產生一把金鑰，放在網址的 `#k=`，第一個用它認領的裝置成為主持人，之後同一把金鑰可以從別的裝置接手。保護只有這把金鑰加 4 個字母的房間代碼，**不要把主持人網址給玩家**。
- **隊伍身分**：隊伍 ID 是公開的（每次狀態廣播都帶著），所以每隊另外有一把只存在自己瀏覽器裡的密鑰，重連時要出示。別人拿到隊伍 ID 也冒用不了。房間預設沒有密碼：任何知道 4 碼代碼的人都能加入（最多 8 隊；一條連線只能代表一隊；每個房間最多 60 條連線，滿了會先關掉最舊的多餘連線，主持人、最早連上的兩台大螢幕和每隊唯一的連線不會被擠掉）。主持人可以在大廳設定**加入密碼**，設定之後新隊伍要輸入密碼才能加入，已經加入的隊伍重連時不用輸入。公開網址建議設定密碼。
- 怪物美術：圖鑑有 20 隻小怪和 3 隻首領（深淵小黑龍、深海大王烏賊、不死火鳥），每隻都有自己的料理圖；預設題庫每場開局重新抽怪：每間房一隻不重複的小怪，首領從 3 隻裡抽一隻（題庫編輯器的「每場隨機抽怪」）。同一隻小怪放在好幾間房時，再出場會換顏色、戴配件、名牌多一個稱號（見[題庫指南](question-bank.md#預設題庫)）。
- 最多 8 隊；隊伍多、房間多時，大螢幕的活地圖會把較早的房間收進最左邊的入口格，讓地圖塞得進畫面，還沒有真人實測過。
- 一次只支援單一場次的簡單使用情境，沒有多場並行的設計。
