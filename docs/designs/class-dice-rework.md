# 設計：職業骰改版（暴擊骰改成料理骰，倍率統一成 5 個數字）

狀態：**草案，等站長核准**。只有設計和模擬，還沒改遊戲。活動結束後才實作。
模擬器：`scripts/balance-sim.ts`（分支 `tooling/class-dice-rework-sim`）。全部數字在 `balance-rework-results.txt`。

## 為什麼改

現在答對後擲的骰子有三種名字（暴擊骰、答對骰、技能骰），廚師和盜賊讀的是「別人的骰」，倍率有 ×0.1、×0.8、×1.3、×1.5、×2 和「多一半」好幾種。改版後：

- 骰子只有三種：**說服檢定**、**料理骰**（每隊答對都擲）、**自己職業的骰**。
- 倍率只有 5 個：**×0.1、×0.8、×1.2、×1.5、×2**。沒有別的小數。
- 這是預計的最後一次大調整。

## 站長已經決定的

| 項目 | 決定 |
|---|---|
| 暴擊骰、答對骰 | 拿掉。改成**料理骰**：每隊在回合制答對後都擲一顆 |
| 料理骰 20（每隊） | 這題分數 ×1.5 |
| 料理骰 1、2–6（非廚師） | 不扣分，只換菜名和圖 |
| 職業骰的 20（廚師料理、戰士、盜賊偷襲） | ×2 |
| 成功 7–19 | 廚師 ×1.2、盜賊偷襲 ×1.5、戰士代答拿 ×0.8 |
| 小失敗 2–6 | 只有廚師 ×0.8（方案 Y 想改這條，見下） |
| 大失敗 1 | 廚師 ×0.1；戰士照舊扣掉整題 |
| 廚師 | 保留四段料理骰，一次一顆 |
| 盜賊 | 按「偷襲」就立刻擲偷襲骰，答錯沒有加成 |
| 盜賊 20 | ×2（偷襲倍率 +0.5）、首領扣 3 顆心 |
| 戰士 20 | 照舊多扣首領 1 顆心 |
| 尾刀 | 一律純 4d20，任何職業都不影響 |
| 藥水 | 說服檢定、每個職業自己的骰、任何一隊的料理骰都能用 |
| 一般房答錯 | 只剩逃跑・換房 |
| 料理的圖 | 1：`dish-burnt`（共用一張新圖）；2–19：原圖；20：`<dish>-legend`（每道菜一張新圖）。另一條美術線畫 |
| 平衡的手段 | 只能用整數的說服加值和藥水規則，不加新的小數 |

料理骰不影響首領的愛心（現在暴擊骰 20 會多扣 1 顆，改版後沒有）。

四段照舊，共用：**1 大失敗／2–6 小失敗／7–19 成功／20 大成功**。

## 各職業

### 每一隊：料理骰

回合制答對後擲（一般房和首領輪流階段；搶答階段、叉路和神秘房的獎勵、尾刀不擲）。戰士擲骰代答成功也算答對，一樣擲料理骰。

| 骰子 | 非廚師 | 廚師 | 菜名 | 圖 |
|---|---|---|---|---|
| 1 | 不變 | ×0.1 | 焦黑名單 | `dish-burnt` |
| 2–6 | 不變 | ×0.8（方案 Y：不變） | 失手前綴＋原菜名 | 原圖 |
| 7–19 | 不變 | ×1.2 | 原菜名 | 原圖 |
| 20 | ×1.5 | ×2 | 傳說前綴＋原菜名 | `<dish>-legend` |

倍率乘在這題拿到的整題分數上（偷襲、祝福、詛咒都算完之後），四捨五入。

菜還是被打倒那隻怪物自己的料理（`lib/monster-catalog.ts` 的 `dish`），骰子只換前綴。〇〇 是原菜名，例如「龍息烤龍尾」。

| 段位 | 菜名（隨機抽一個） |
|---|---|
| 1 焦黑 | 碳化的〇〇／冒黑煙的不明物體／曾經是〇〇的東西／鍋底刮下來的〇〇／焦黑殘渣／黑暗料理・〇〇 |
| 2–6 失手 | 半生不熟的〇〇／有點鹹的〇〇／忘了調味的〇〇／煮過頭的〇〇／賣相不佳的〇〇／手滑版〇〇 |
| 7–19 | 〇〇（原菜名） |
| 20 傳說 | 傳說級〇〇／主廚私房〇〇／黃金〇〇／會發光的〇〇／皇家御用〇〇／一生一次的〇〇 |

料理的短評（`comment`）建議每段各備 2–3 句共用的，例如 1：「吃起來像木炭，因為就是木炭。」；20：「吃完的人都說看見了光。」。

### 盜賊：偷襲骰（按下去就擲）

輪到自己、題目出來後按「偷襲」，房間立刻擲偷襲骰，擲完才作答。同一題只能按一次。

| 骰子 | 結果 | 次數 |
|---|---|---|
| 1 | 被發現，偷襲沒成 | 扣掉 |
| 2–6 | 沒抓到時機，偷襲沒成 | 退回，這題不能再試（方案 Y：扣掉） |
| 7–19 | 偷襲就位：這題答對 ×1.5、首領扣 2 顆心 | 扣掉 |
| 20 | 完美偷襲：這題答對 ×2、首領扣 3 顆心 | 扣掉 |

答錯就沒有加成，次數也不退。尾刀的 4d20 不乘。偷襲成功又答對後，一樣擲料理骰（20 再 ×1.5）。

### 戰士：擲骰代替答題

1 答錯並扣整題；2–6 答錯；7–19 答對拿 ×0.8；20 答對拿 ×2，首領多扣 1 顆心。新增：可以喝藥水。

### 法師、牧師、沒選職業

技能骰和祈禱骰不變。沒選職業沒有職業骰，只擲說服檢定和料理骰。

## 還沒決定：方案 X 或方案 Y

照對照表直接套，廚師 7–19 降到 ×1.2 後只剩 21.6／19.8%，盜賊 ×1.5 是 30.8／31.4%，最大差 9.2／11.6（1 萬場）。說服加值是弱旋鈕：廚師 +6、盜賊 +0 只到 8.1／8.2；廚師 +10、法師 +8 再加「一瓶藥水管 3 次料理骰」也只到 5.1／6.1。所以需要下面其中一案。

| | 方案 X（完全照站長條件） | 方案 Y（建議） |
|---|---|---|
| 廚師的藥水 | **這道菜升一級**：1→×0.8、2–6→×1.2、7–19→×2、20 還是 ×2 | 跟大家一樣擲兩顆取高；一瓶管接下來 **2 次**料理骰 |
| 其他職業的藥水 | 下一顆骰擲兩顆取高 | 同左 |
| 廚師 2–6 | ×0.8 | **不扣分**（跟其他隊一樣只換菜名） |
| 盜賊偷襲 2–6 | 次數退回 | **次數扣掉** |
| 說服加值 | 法師 +6、盜賊 **−3**、牧師 +2、廚師 +8、沒選 +1、戰士 +0 | 法師 +6、盜賊 +3、牧師 +2、廚師 +8、沒選 +1、戰士 +0 |
| 最大差（每隊約 2 瓶藥水，4 萬場） | 2.0／2.9 | 2.2／2.1 |
| 不給藥水時（1 萬場） | 廚師 21.9／21.4，最大差 8.3／9.2 | 廚師 23.9／26.5（盜賊加值 +0、一瓶管 1 次的版本） |
| 每隊約 4 瓶時（1 萬場） | 廚師 32.6／30.7，最大差 8.2／5.8 | 廚師 26.2／25.5（同上） |
| 廚師一場的傳說級料理 | 1.15／0.88 道（60–68% 的場次至少一道） | 0.42／0.41 道（約 34%） |

方案 X 的平衡靠主持人剛好每隊給 2 瓶左右，而且有負的說服加值。方案 Y 跟站長的對照表有兩處不同（廚師 2–6、盜賊 2–6），但藥水多給少給都不會壞。

## 勝率

4 隊、6 個選項（五個職業＋沒選）隨機抽 4 個，每組 40,000 場（每個職業 ±0.5）。主持人每輪有 10% 機率給沒有藥水的隊一瓶（每隊一場約 2 瓶）。一般房只有逃跑・換房。「最大差」只算五個職業。現行規則那一列是 60,000 場。

## 傳說級料理多常出現

每隊都擲之後，傳說級料理（任何一隊擲到 20）：

| | 活動結構 | 預設結構 |

| 4 隊：一場擲幾次料理骰 | 28 | 29 |
| 4 隊：一場幾道傳說級 | 1.4 | 1.5 |
| 4 隊：至少看到一道的場次 | 76% | 77% |
| 8 隊：一場擲幾次料理骰 | 46 | 47 |
| 8 隊：一場幾道傳說級 | 2.3 | 2.3 |
| 8 隊：至少看到一道的場次 | 90% | 91% |

8 隊是 8,000 場，假設首領血量和 4 隊時一樣。25 張 `<dish>-legend` 裡指定的某一張，8 隊場平均約 11 場出現一次。畫面時間：擲骰次數跟現在的暴擊骰差不多，沒有變多也沒有變少。

## 模擬的假設和限制

- 非廚師的料理骰 1 和 2–6 不扣分；藥水可以用在任何一隊的料理骰（站長已同意）。模擬裡非廚師不會把藥水花在料理骰上，都用在說服檢定或職業骰。
- 隊伍拿到藥水後用在下一顆能用的骰上，沒有模擬「留到關鍵時刻」。
- 盜賊只在知道答案時偷襲；同一題只擲一次偷襲骰。
- 沒有模擬 8 隊的勝率，只算了 8 隊的料理骰次數。
- 「沒選職業」只有 14% 左右，現行規則也是這樣，這次沒有處理。

重跑（活動結構再加上面那串參數；`PGIVE=0.1` 是藥水假設）：

- 方案 X：`REWORK=1 DISHALL=1 CHEFPOT=up PGIVE=0.1 LIB='CHEF_MULTIPLIERS=[0.1,0.8,1.2,2];CHECK_BONUS={mage:6,thief:-3,cleric:2,chef:8,none:1,warrior:0}' taskpolicy -b node --no-warnings scripts/balance-sim.ts 40000`
- 方案 Y：`REWORK=1 DISHALL=1 SNEAKLOSE=1 CHEFPOTN=2 PGIVE=0.1 LIB='CHEF_MULTIPLIERS=[0.1,1,1.2,2];CHECK_BONUS={mage:6,thief:3,cleric:2,chef:8,none:1,warrior:0}' taskpolicy -b node --no-warnings scripts/balance-sim.ts 40000`
- 現行規則基準：只留 `PGIVE=0.1`。

## 走過但沒採用的

- 只有廚師擲料理骰、偷襲 ×1.4、法師 +6：最大差 1.2／2.1（6 萬場），是試過最平衡的一組，但傳說級料理只有 26–45% 的場次看得到，站長改選每隊都擲。
- 每隊都擲、廚師 2–6 ×0.9（其他照舊倍率）：0.9／2.1（4 萬場）。用到調色盤外的小數，不採用。
- 廚師擲兩顆取高、廚師不失手 ×1.25、別隊煮焦時廚師撿分：都能調到 3 以內，但各自要新的小數或強度跟隊伍數有關。
