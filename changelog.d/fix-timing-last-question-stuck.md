### Fixed
- The host's 「沒人答對，換下一題」 (nobody got it, next question) on a boss-phase timing question that is the phase's last unrevealed one now uses it up instead of bringing the same question back, so a question the big screen cannot play no longer traps the host. An earlier phase ends and its next phase starts, and the last phase moves on to questions already revealed. Before, the host could only end the game. A round that closes with no tap still brings the question back for a replay.
