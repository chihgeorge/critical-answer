### Changed
- 部署後檢查 `npm run canary:live` 現在每種題型都過得去：選擇、排序、填空（含說服骰）、圖片和影片題、記憶題、搶答題和多欄聽歌題都照答案答對；卡點題和放不出來的聽歌搶答題由主持人跳過，印 `note="skipped: ..."` 不算壞掉。神秘房、占卜師、叉路和首領階段卡也都會走過去，首領被打倒時剩下的步驟略過。
- 新選項 `--turns N`（每輪玩 N 個回合）和 `--boss`（開始後把 `CANARY-1` 送王房）。它仍然不帶金鑰、只玩預設題庫；部署指南寫了怎麼用測試金鑰在本機放進別的題庫來試。
