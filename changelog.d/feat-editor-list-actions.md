### Added
- The bank editor lists each question as one line (number, kind, question, answer, media mark, ⚠ when a save is blocked); tap it to open the whole question, or use 「全部展開」. A search box finds questions anywhere in the bank and opens the one you pick.
- Each question has a ⋯ menu: move up or down, move to another difficulty or boss phase (places a save would refuse are greyed out with the reason), copy, and delete. A delete can be undone from the save bar (「已刪除第 n 題 · 復原」).

### Changed
- Changing a question's kind keeps its answer where it fits: a fill-in answer becomes the correct option, the correct option becomes the fill-in answer, options and sort items carry over. The editor asks first only when something typed would be dropped.
